# 护肤内容工作台

用于整理中文美容护肤产品资料、文案版本、图片、科普内容和任务的基础版。使用原生 JavaScript 模块、HTML 和 CSS，配一个轻量的 Node.js 本地服务器。无需安装第三方依赖或配置数据库。

## 启动

安装 Node.js 22 或更新版本，然后运行：

```sh
git clone https://github.com/luotuo7008/luotuo.git
cd luotuo
npm start
```

浏览器打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。开发时可用 `npm run dev`；如端口被占用，可运行 `PORT=4174 npm start`。服务器默认只监听本机。

## 页面

| 页面 | 可以做什么 |
| --- | --- |
| 产品目录 | 查看品类、规格、负责人、状态和资料备注 |
| 营销文案版本 | 查看渠道、审核状态、版本正文，切换同一主题下的版本 |
| 图片素材 | 预览示意图，查看关联产品、用途及使用权 |
| 皮肤生理结构科普 | 阅读表皮、真皮和皮下组织的说明、示意图及参考来源 |
| 任务看板 | 按状态查看任务，用卡片中的下拉框移动任务 |
| 筛选视图 | 组合关键词、模块、分类和状态，在跨模块结果中打开详情 |

数据为演示资料；可选字段没有确认时存为 `null`，界面统一显示“未定”。任务状态保存在当前浏览器的本地存储中，不会同步到 GitHub 或其他设备。其余资料来自示例数据，暂未提供录入界面。

## 数据与扩展

- `src/data.js` 定义五类记录及字段。产品、素材、文案和任务通过 `productId` 关联；文案以 `seriesId` 和版本号区分同主题的版本。
- `src/app.js` 处理页面导航、详情、筛选和任务状态。新增示例可先修改数据文件；新增静态资源时更新 `server.mjs` 的文件列表。
- 后续可接入数据库与账号权限，实现多人编辑；为文案增加审核与发布记录，为素材增加上传和授权管理，为科普增加来源管理与复核流程，并支持保存常用筛选。
